     1→# BS-Lokossa Application Web - Worklog
     2→
     3→## Projet
     4→Application web de gestion du Bureau Syndical de Lokossa (BS-Lokossa) pour la Fédération des Étudiants Universitaires Associés (FEUA) au Bénin.
     5→
     6→## Stack Technique
     7→- **Frontend**: Next.js 16 (App Router) + React + TypeScript
     8→- **Styles**: Tailwind CSS 4 + shadcn/ui + Framer Motion
     9→- **Backend**: API Routes Next.js + Prisma ORM (SQLite)
    10→- **State**: Zustand (client state)
    11→- **Charts**: Recharts
    12→- **Auth**: Cookie-based session with bcryptjs
